# Cloud Foundations Practice

Неофициальный тренажёр для подготовки к курсу AWS Academy Cloud Foundations (ACFv2):
knowledge checks M01–M10, вопросы по лабам, режим подготовки к Midterm Quiz (недели 1–6)
и вкладка «Слайды» с Student Guide PDF модулей M01–M10 (`slides/`, просмотр через PDF.js).

Статический сайт без сборки: `index.html` + `data-kc.js` + `data-labs.js`.
Прогресс хранится в localStorage браузера.
