# Cloud Foundations Practice

Неофициальный тренажёр для подготовки к курсу AWS Academy Cloud Foundations (ACFv2):
knowledge checks M01–M10, вопросы по лабам, режим подготовки к Midterm Quiz (недели 1–6),
конспекты по лабам («Что делали» и «Что происходит») и сборник ключевых моментов слайдов M01–M10.

Статический сайт без сборки: `index.html` + `data-kc.js`, `data-labs.js`, `notes-did.js`, `notes-how.js`, `modules-notes.js`.
Прогресс хранится в localStorage браузера.

Папка `research-methods/` — отдельный тренажёр к мидтерму по Research Methods in IT (лекции 1–4.2):
конспекты, тест на 183 вопроса и карточки с терминами. Ссылка в шапке главной страницы.
